# Hi, I'm Lucas 👋

Full-stack web developer based in Madrid. I build applications with
**React, Node.js, Express and MongoDB**.

I came to development from eight years in retail, where I led a team
and dealt with customers every day. I finished the Ironhack web
development bootcamp in 2024 and I have been building and shipping
projects since then.
